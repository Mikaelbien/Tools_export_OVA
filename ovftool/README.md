# ovftool

Copie portable de VMware OVF Tool, utilisée en priorité par `export_ova.py`.

Pour la mettre en place, copier le contenu du dossier d'installation
(`C:\Program Files\VMware\VMware OVF Tool\`) dans ce dossier, de façon à obtenir `ovftool/ovftool.exe`.

Les binaires ne sont pas versionnés dans git (voir `.gitignore`, ~95 Mo, licence VMware/Broadcom) ;
seul ce README l'est.
